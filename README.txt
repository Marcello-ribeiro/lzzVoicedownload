LZZ VOICE - SITE DE DOWNLOAD
============================

ARQUIVOS PRINCIPAIS
- index.html
- style.css
- script.js
- assets/logo.png
- assets/favicon.ico
- downloads/

COMO COLOCAR OS INSTALADORES
1. Copie o instalador do PC para a pasta downloads e renomeie para:
   LZZ-Voice-Setup.exe

2. Copie o APK para a pasta downloads e renomeie para:
   LZZ-Voice.apk

3. Abra index.html para testar.

PARA HOSPEDAR
Você pode subir a pasta inteira na Vercel ou Netlify.

IMPORTANTE
Algumas plataformas de hospedagem podem limitar o tamanho máximo de arquivos.
Se os instaladores forem muito grandes, hospede os arquivos em outro lugar e
altere os href dos dois botões de download no index.html para os links finais.
